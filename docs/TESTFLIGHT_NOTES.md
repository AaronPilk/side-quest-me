# Internal iPhone beta — 1.0.0 (5)

This build responds to the 20 screenshot feedback reports. It connects to live Sidequest services. Videos and series remain private until you explicitly publish.

Start with normal Create → Find my quests:

- OpenAI now creates a playable private experience from your actual group, time, budget, intensity and confirmed preferences. No separate Draft with AI detour is needed. Generation can take about a minute.
- Use your current area or choose a town. Apple Maps searches several activity types and the app suggests a destination; a specific place is optional. A listing is not a confirmed booking or ticket.
- Full Send rejects quiet photo/craft tasks with inflated round counts. Try friends at a venue, with and without a named place, and tell us whether the actual activity is worth doing.
- Booking cost, permission and equipment questions appear only after a relevant idea is suggested. Unknown booking prices are labeled for checking. Your answers should never silently turn into Chill or a different group size.
- A fallback plan is clearly labeled if AI cannot finish a strong idea. Generated quests currently award no XP/points; this is shown before accepting. You can film one, publish its story and turn it into a series later.

UI fixes:

- Budget has a slider, exact-amount button and Whole group / Each person pills. Travel uses visible choices.
- Normal Create no longer asks generic More options before suggesting anything. Question controls and Continue fit above the bottom navigation.
- Account setup and preferences use compact screens with bottom actions. The ChatGPT summary step shows a paste box and Continue saves it. The copy/open prompt is no longer repeated on every question.
- ChatGPT handoff now uses its supported native universal link. Please test with ChatGPT installed; the browser remains a fallback.
- The misleading profile-update banner and underlying social-profile read failure are fixed.

Please test accepting → filming/importing → saving/exporting → Turn into a series → Create Part 2. Also try location denied, returning after leaving the app, summary edits/removal, and profile saving. Report the screen, chosen plan and whether it repeats.

Live event inventory is not configured: the app does not claim current concerts or ticket availability. Camera/audio interruptions, installed ChatGPT handoff and Photos export still need physical-iPhone feedback. Recording supports up to 60 seconds. Existing email sign-in remains; Sign in with Apple is not included.
