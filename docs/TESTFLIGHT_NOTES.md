# Internal iPhone beta — 1.0.0 (4)

This beta connects to live Sidequest services. Videos and new Series stay private until you explicitly publish them.

Focus on Create → Draft with AI for this build's changes:

- Try the same theme with different groups and intensities. Saved interests, participation preferences and boundaries should influence the proposal while your current group's exact size, budget and time remain authoritative.
- Full Send has stricter audience/experience checks. It may return a clear no-fit message. Please report those cases with the plan and brief you entered, as well as ideas that are too mild, confusing or not worth doing.
- In the AI plan, choose a venue and try the age eligibility, venue permission and optional adult-nightlife choices. These are self-declarations, not age verification. Change the group, headcount or setting: old confirmations and venue charges should clear rather than carry into a new plan.
- Generation runs after explicit OpenAI consent and can take around a minute. Preview and use an editable draft, save it, then reopen it. Generated original drafts still require review before becoming runnable recommendations.

Quest quality is still being tuned. A live five-friends Full Send evaluation produced ideas that were too mild and were rejected. This build does not connect nearby Apple Maps places or live events to AI generation. Ordinary Create recommendations still use the existing catalog. Live event inventory is not configured.

Continue checking the existing flows:

- Profile → Account & quest preferences: edit/reset answers, skip and resume setup, import or remove a ChatGPT summary, then reopen the app. Skips should stay unknown. Try Copy prompt and open ChatGPT on your phone; paste/send the prompt yourself and return with the summary.
- Accept and film a quest → Turn into a series → Create Part 2 → publish a finished part. Existing videos should remain attached, drafts private, and repeated quests should not earn duplicate awards within their cooldown.
- Record multiple takes, restore a draft, import gallery footage, try timer/front-rear camera/teleprompter/photo overlay, finish the reel, and save through the iPhone share sheet. Check playback and the Sidequest watermark.
- Try nearby place search with location allowed and denied, plus Discover search and Profile tabs.

Please report the screen/action, iPhone model, iOS version, and whether the issue repeats after reopening. Camera/audio interruptions, installed ChatGPT handoff, sign-in callbacks and saving to Photos need physical-device testing. Recording supports up to 60 seconds. Sign in with Apple is not included; existing email sign-in remains.
