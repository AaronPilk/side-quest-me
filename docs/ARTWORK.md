# Sidequest editorial artwork

The three decorative photographs in `public/artwork/` were generated for this app on September 30, 2026 with the image-generation tool. They are inspiration artwork, not user posts, verified venue photographs, or representations of nearby events. The welcome carousel describes them as imagination; quest cards use them as decorative images with empty alternative text and retain separate readable quest titles.

The final direction is premium, photorealistic lifestyle photography with subtle violet accents. It replaces the earlier tan cards and the rejected fantasy/illustration direction. The existing approved Sidequest logo is rendered separately; no generated logo replaces it. Images are delivered as 1200 × 800 WebP assets.

## Motion and accessibility

The welcome carousel supports horizontal swiping, direct slide buttons, and pause/play. Automatic movement stops during interaction or when the page is hidden; reduced-motion users start with it paused. Quest recommendations use static photographs so the activity remains readable.
